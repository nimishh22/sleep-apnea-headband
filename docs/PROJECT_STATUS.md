# Project status

Last updated: 2026-11-23

## Implemented in this repository

- ESP32-C3 firmware scaffold for MAX30102, LIS3DH and a raw analog input.
- Serial JSON sample reporting.
- CSV loading and timestamp validation.
- Basic offline signal filtering utility.
- Descriptive feature extraction.
- Transparent exploratory candidate score.
- Binary classification metrics for supplied labels/predictions.
- Python unit tests and a GitHub Actions test workflow.
- Synthetic example recordings and documentation.

## Not implemented or validated

- A dedicated, validated EEG acquisition chain.
- fNIRS hardware or processing.
- A trained sleep-apnea model.
- Clinical event detection.
- Clinical sensitivity/precision targets.
- End-to-end real-time inference on the ESP32-C3.
- Closed-loop haptic/audio intervention.
- Human-subject testing or clinical validation.

## Release gate

Do not describe this as competition-ready clinical technology. It may be demonstrated as an engineering/research prototype after the team verifies the firmware build, runs automated tests, checks the sensor wiring, and rehearses the synthetic-data demonstration.
